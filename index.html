Platform capabilities

One governed path from raw signal to validated model evidence.

CardioSignal is designed around explicit contracts and fail-closed boundaries. The platform separates signal handling, evidence qualification, model development, runtime execution, and evaluation so each step can be inspected independently.

Signal

Deterministic ECG processing

Controlled resampling, filtering, fixed-length preprocessing, signal-quality evidence, segmentation, and provenance.

Data

Evidence-bound datasets

Dataset manifests, subject-disjoint splits, local artifact verification, hash integrity, and explicit test-access boundaries.

Models

Reproducible development

Protocol-derived seeds, bounded trial spaces, train-only balancing, validation-only calibration, and immutable candidate freeze.

Runtime

Secure ONNX execution

CPU-only reference execution, model and preprocessing binding, environment fingerprints, and runtime evidence export.

Validation

Locked evaluation

Token-gated test access, model/preprocessing verification, benchmark contracts, threshold policies, and auditable receipts.

Robustness

Controlled perturbation analysis

Deterministic noise, gain, baseline-wander, and sample-dropout scenarios with prediction-drift controls.

Public scope

Engineering infrastructure, not a clinical claim.

CardioSignal is currently positioned as research and engineering infrastructure. This public website does not expose private source code, proprietary algorithms, model weights, confidential validation internals, or patient data.

  • No patient data is published here.
  • No clinically trained ECG weights are distributed here.

  • No medical-device certification or regulatory clearance is claimed.
