# CardioSignal Website

Official public showcase for the **CardioSignal Intelligence Platform**.

**Public positioning:** Evidence-Governed ECG Intelligence.

This repository is intentionally separated from the private CardioSignal engineering repository. It contains only static public presentation files and must not contain proprietary implementation details, private validation internals, patient data, credentials, model weights, internal prompts, confidential research, or reconstructable system internals.

## Art direction

The public site uses a project-specific interpretation of the shared TheArchitectMax visual language:

- chiaroscuro: strong hierarchy through light/dark contrast;
- tenebrism: a predominantly dark composition with a focused biomedical light source;
- sfumato: soft atmospheric transitions, glow, haze, and low-contrast depth;
- CardioSignal signature: warm biological amber paired with cool analytical cyan.

The design uses original CSS/SVG visuals only. No external stock image is used.

See [IMAGE_CREDITS.md](IMAGE_CREDITS.md) for visual provenance.

## Public scope

The website communicates only high-level project information:

- product purpose and problem framing;
- intended research/engineering relevance;
- high-level capabilities;
- non-sensitive design principles;
- conceptual architecture;
- current software-engineering milestone and verification status;
- research/engineering and medical-safety boundaries.

The public architecture is intentionally non-reconstructive. Private algorithms, source code, exact internal schemas, security configuration, model weights, datasets, and proprietary implementation logic are excluded.

## Technology

- Static HTML
- CSS
- Minimal vanilla JavaScript
- Original SVG visual assets
- No runtime framework
- No external JavaScript CDN
- No analytics or tracking
- No payment, authentication, database, or SaaS runtime

## Medical boundary

CardioSignal is presented as research and engineering infrastructure. The website does not provide diagnosis, treatment recommendations, clinical-performance claims, medical-device certification, or regulatory-clearance claims.
