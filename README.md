# CardioSignal Website

Official public website for the **CardioSignal Intelligence Platform**.

**Public positioning:** Evidence-Governed ECG Intelligence.

This repository contains only the public-facing static website. It is intentionally separated from the private CardioSignal engineering repository and must not contain proprietary implementation details, private validation internals, patient data, credentials, model weights, or confidential IP.

## Site

When GitHub Pages is enabled for this repository, the intended URL is:

https://thearchitect-max.github.io/CardioSignal-Website/

## Public scope

The website communicates:

- high-level product positioning;
- public capability descriptions;
- architecture at a non-sensitive conceptual level;
- software-engineering validation status;
- current public release milestone;
- research/engineering and medical-safety boundaries.

## Technology

- Static HTML
- CSS
- Minimal vanilla JavaScript
- No runtime framework
- No external JavaScript dependency
- No analytics or tracking by default

## Medical boundary

CardioSignal is currently presented as research and engineering infrastructure. The public website does not claim diagnosis, treatment recommendation, clinical performance, medical-device certification, or regulatory clearance.
